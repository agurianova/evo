pMHC-TCR recognition. Predict binder (label=1) vs non-binder (label=0).

DATA
ImmRep25: 8936 complexes, 20 pMHCs, 1000 TCRs. Sequences (mhca, epitope, tcra, tcrb), PDB, MaSIF (tcr.npz, pmhc.npz with desc / desc_flipped).
TCR tables already store TRAV/TRAJ/TRBV/TRBJ gene names and CDR3. CDR1/2 are IMGT germline loops of the named V allele (substring of the chain); FR1/2/3 flank them; FR4 is 11 aa after CDR3. Cys23/Trp41 is only a fallback.

DATASET STRUCTURE (important for loss / sampling design)
- Split unit is **pMHC** (`mhc_epitope_id`), not complex and not TCR. Frozen r0: **12 train / 4 val / 4 test** pMHCs (allele-stratified); **no pMHC appears in two folds**. TCRs may recur across folds.
- Strong **class imbalance**: overall ~10% binders (train ≈541/5378, val ≈183/1786). Per pMHC roughly **40–50 positives vs ~400 negatives** (~9–11% pos); imbalance is similar across pMHCs, but peptides still differ in difficulty.
- Many negatives share the same pMHC as a few positives → ranking **within one pMHC** matters more than global class prior. Fitness is **Macro-AUCPR** (unweighted mean over the 4 val pMHCs), so one easy peptide must not dominate training.
- Train columns used by validators include `label`, `mhc_epitope_id`, sequences, `pdb_path`, `masif_tcr_path`, `masif_pmhc_path`. `score()` does not receive labels.

KNOWN SIGNALS (use them; do not rediscover by flipping MaSIF orientation)
- Within one pMHC, TCR variable genes separate positives from negatives well — but **do not feed TRAV/TRBV/TRAJ/TRBJ names as features**. Use what the V allele **encodes**: germline CDR1/CDR2 and FR structure/composition, how those loops sit relative to CDR3 and the pMHC, and interactions of those structural cues with epitope / PDB / MaSIF patches. A strong extra route: **assign MaSIF surface points to nearest PDB amino acids** (`load_pdb`: `xyz`/`aa`/`chain`) and summarize complementary MaSIF mass / embeddings by residue identity and by CDR1/2/FR vs CDR3 (or peptide/MHC) loop bins — structural V-gene signal without gene labels.
- Mean MaSIF embeddings on the TCR (tcr.npz, already TCR-direct / desc_straight) differ between binders and non-binders of the same pMHC, but the pooled 80-d mean is a weak proxy. Do **not** treat “are the surface descriptors similar?” (cosine / identity) as the interface test. The binder signal is **complementarity** — how **close** TCR and pMHC descriptors are, and whether matches form a **large, coherent contact patch** (a protrusion seating in a matching depression), not two identical surfaces. Preferred comparison (keep pooled 80-d descriptors as well):
  1. For every TCR MaSIF point, find the nearest pMHC point by **L2** (ordinary Euclidean distance on the descriptor vectors).
  2. Count a pair as a match only if that L2 distance is **< 1.7**.
  3. Merge neighboring matched points (on MaSIF **xyz**) into **connected components**.
  4. Measure **each component’s size** (n_points / area_frac).
  5. From matched **xyz**, measure the **trace length** of the footprint (span / geodesic / path length of the connected match).
  6. **Keep pooled descriptors** (mean 80-d TCR + pMHC) concatenated with those patch/trace stats.
  Complementary-match **spots / patches** are a **weak cumulative** signal: averaging positive vs negative patches inside one pMHC shows clear differences in **location**, **brightness (NN)**, and **patch area**. Prefer those summaries (CDR3 fraction, distance to peptide, area / n_components, mean/min NN, component size, trace length) over pooled cosine alone. Go further when useful: **MaSIF↔PDB AA ownership**, richer complementarity (soft/top-k/mutual NN, descriptor products along matches), and **cross-attention between MaSIF TCR and pMHC patch embeddings** (subsampled desc+xyz tokens → MHA TCR↔pMHC → pooled interface features, optionally tagged by nearest PDB AA/loop). CREATE_SURFACE once; then CHANGE_SURFACE to enable spots. Do not keep toggling pmhc_flipped / tcr_direct after they are true.
- Training should **force within-pMHC contrast**: separate binders from non-binders of the same pMHC and learn a rule that generalizes to held-out pMHCs (primary within-pMHC ranking; global BCE/focal/contrastive only as light aux). Given ~1:9 imbalance and ~45 positives per peptide, experiment with losses/sampling that respect this (pairwise/listwise within pMHC, hard-negative mining inside a pMHC, focal/asymmetric aux, equal weight per pMHC, balanced pos/neg batches per peptide) — not global class weighting alone.
- For free-form Python genomes: aim for a **dual interface** — (1) **geometric** learning on PDB Cα **and** MaSIF xyz (kNN/radius graphs, short MP/GAT, MaSIF↔PDB ownership), and (2) **cross-attention pMHC↔TCR** on **both** PDB residue tokens and MaSIF patch tokens, then fuse the two attended pools. MultiheadAttention / traces / V-gene-without-names features remain in scope. Do not stop at Linear/MLP early-concat, mean-pooled MaSIF, or a single modality-token MHA over flat vectors.
- tcr.npz is already direct; pmhc.npz is already flipped.

WHAT THE COMPILER TRAINS
The mutator patches GENOTYPE_JSON then regenerates a Python script; validate() execs entrypoint().
- sklearn logistic only if num_layers==1 and model.type=mlp_features and no GAT/cross/seq encoder.
- Otherwise a PyTorch MLP head: dropout, residual, optimizer (adamw/adam/sgd), scheduler (none/cosine/step), batch_size, lr, weight_decay. Primary loss is within-pMHC ranking; genotype.loss is 0.1× BCE/focal/contrastive aux.
- seq_dual_encoder trains a real CNN or Transformer on residue tokens (encoders.sequence.arch). CHANGE_SEQUENCE arch cnn/transformer on mlp_features promotes type to seq_dual_encoder so the Python contains SeqEncoder. protein_lm does **not** promote: it stays mlp_features and reads the frozen ESM-2 8M cache.
- seq_cross_encoder (or mlp + interaction.method=cross_attention, which promotes to seq_cross) trains **pooled** MultiheadAttention: one peptide/MHC token vs one TCR token. Not residue-level, not table self-attention.
- multimodal_cross_attn trains MHA across modality tokens (sequence vs MaSIF vs PDB).
- pdb_gnn trains a GAT on the Cα graph. se3_transformer is a Cα distance kernel (`exp(-0.5 d)`), not SE(3).
- masif_siamese trains a shared MLP two-tower on the 80-d pooled TCR / pMHC descriptors. masif_patch_cross_attn trains patch MHA only (no table self-attention).
- interaction.method or fusion = cross_attention trains pooled peptide↔TCR MultiheadAttention.
- CHANGE_SURFACE complementary spots (NN L2 < 1.7) add frozen localization features (CDR3 fraction, distance to peptide, n_components).
- protein_lm uses the frozen local ESM-2 8M cache (mhca/peptide/tcra/tcrb npz, no network). Fitness is Macro-AUCPR (log Macro-AUC0.1).

SPLIT r0 (frozen)
12/4/4 pMHCs, allele-stratified 6+6 / 2+2 / 2+2.
No pMHC in two folds. All pairs are kept. TCRs may appear in more than one fold.
validate() uses train+val. test.py uses train+test. Test labels are not used in validate().

API
entrypoint() returns an object with:
  fit(train_df) -> None
  score(rows_df) -> 1d float scores, higher = binder
score() does not receive label.

FITNESS
Macro-AUCPR over the 4 val pMHCs. Also log Macro-AUC0.1 (ImmRep25 McClish, FPR<=0.1).
