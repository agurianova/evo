pMHC-TCR recognition. Predict binder (label=1) vs non-binder (label=0).

DATA
ImmRep25: 8936 complexes, 20 pMHCs, 1000 TCRs.
Per complex: sequences (mhca, epitope, tcra, tcrb), Boltz-2 PDB, MaSIF surface (tcr.npz, pmhc.npz).
TCR tables store TRAV/TRAJ/TRBV/TRBJ and CDR3.

DATASET STRUCTURE
- Split unit is pMHC (`mhc_epitope_id`). Frozen r0: 12 train / 4 val / 4 test pMHCs (allele-stratified); no pMHC in two folds. TCRs may recur.
- Class imbalance ~1:9 (~10% binders; ~45 pos vs ~400 neg per pMHC).
- Fitness is Macro-AUCPR (unweighted mean over 4 val pMHCs). Also log Macro-AUC0.1.
- Train columns: `label`, `mhc_epitope_id`, sequences, `pdb_path`, `masif_tcr_path`, `masif_pmhc_path`, `esm_*_path`. `score()` does not receive labels.

ASSET LAYOUT
- PDB: chains A/B = TCRα/β, C = peptide, D = MHC. `load_pdb(pdb_path)` returns xyz, aa, chain, plddt. plddt is the ATOM B-factor column.
- MaSIF: `tcr.npz` stores `desc_straight`; `pmhc.npz` stores `desc_flipped`. Each archive has an 80-d descriptor and xyz. `load_masif()` returns a 64-point subsample. Do not swap the two descriptor keys.
- ESM-2 8M cache: `load_esm(path)` returns pooled, cls, and residue vectors (320-d).
- Sequences: full chains `tcra_seq`, `tcrb_seq`, `mhca_seq`, `epitope_seq` (not CDR3-only).

API
entrypoint() returns an object with:
  fit(train_df) -> None
  score(rows_df) -> 1d float scores, higher = binder

TRAINING CONTRACT (hard)
- Primary loss: ranking within one pMHC (`mhc_epitope_id`). Pull binders above non-binders of the same peptide–MHC.
- Generalize across held-out pMHCs. Global BCE only as a small auxiliary term.
- Batch or weight by pMHC when useful.

MAP-ELITES
- The archive is 6×6 (`pmhc_tcr_interaction` × `compute_tier`). Behavior is read from the program.
