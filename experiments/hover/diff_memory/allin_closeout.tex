\section*{Setup and run log}

(hop\_depth $\times$ passages\_fetched $\times$ instr\_chars, 150 cells,
\texttt{chains\_bd3d}), paired-bootstrap archive acceptance on per-claim score
vectors (challenger enters only if paired bootstrap beats the cell incumbent), and
--- MEM arm only --- paired card crediting (per-sample gain\_se $\to$ posterior
updates). Problem \texttt{chains/hover/full7\_vectorized} (300 fixed train
claims, soft coverage fitness, per-claim vectors stored); mutator
Qwen3-235B-Thinking; chain executor Qwen3-8B; 250 mutants per run;
\texttt{num\_parents=1}.

bug (estimators must be plain classes; fixed + regression test + preflight);
second launch aborted at the 1h hard gate by the watchdog; third launch = pair 1
(TS 000307), clean finish; night queue auto-launched pair 2 (TS 071628), clean
finish. Both pairs ran under a watchdog with a 1h hard gate and T+3h/T+6h sweeps.

\section*{What the winner evolved}
Relative to the seed (retrieve $\to$ summarize $\to$ query $\to$ retrieve $\to$
summarize $\to$ query $\to$ retrieve\_deep), the P2 MEM winner:
(i) upgrades two of three retrievals to \texttt{retrieve\_deep} (k=10);
(ii) deletes both lossy ``summarize'' steps, generating hop queries directly from
raw passages; (iii) adds an explicit verification step (``output VERIFIED, or name
the specific evidence gap'') whose output drives a targeted final
\texttt{retrieve\_deep} --- a gap-filling retrieval that is nearly free when the
claim is already covered. Structure: 4 tool calls / 3 LLM calls vs the seed's
3 tool / 4 LLM.

\section*{Issues log}
\begin{enumerate}

(T5-W passed by T+6h). Fixed post-run; sweeps now also echo to the log.
\item Outbound internet died mid-campaign: run-finish Telegram messages were lost
(delivered later via a retry queue) and the first A1 re-eval launch hung ---
ambient Squid proxy env + internal LLM IP not in NO\_PROXY (known trap; the launcher
clears proxies but ad-hoc tools must too). Restarted proxy-clean.
\item Ref-resolver/dataclass bug (estimator configs must be plain classes) crashed
the first launch; even the default point path was broken. Fixed with regression
test + launcher preflight.
\item Card injection rate above prereg band in both MEM runs (57.9/61.8\% vs
30--55\%): the shortlist almost always has a card to offer at 250-mutant scale.
Follow-up knob if dilution is suspected: injection probability cap.
\item \texttt{python3 script.py} puts the script dir (not repo root) on
\texttt{sys.path}: two eval scripts crashed on import until given an explicit
repo-root insert.
\end{enumerate}

\section*{Defaults decision for chain experiments}
Evidence-backed recommendation (to be baked into \texttt{problems/chains/README.md}
as the canonical recipe):
\begin{itemize}
\item \textbf{Problem}: vectorized variants (\texttt{full7\_vectorized}-style
per-claim vectors). Enables the paired gate, MMR selection, and paired crediting;
zero incoherent vectors across 984 programs.
\item \textbf{Algorithm}: \texttt{chains\_bd3d} + \texttt{enable\_chain\_structural\_metrics=true}
+ \texttt{program\_format=json\_document}. 27--41 occupied cells vs 13 pre-BD3D;
produced the campaign winner.
\item \textbf{Acceptance}: \texttt{archive\_selector=paired\_bootstrap}. 949 paired
decisions, 0 fallbacks; kills single-eval noise promotions ($\sigma \approx 0.008$).
\item \textbf{Pipeline}: \texttt{guided\_noise} (NOMEM) / \texttt{memory\_guided\_noise}
+ \texttt{memory=full memory/write=live memory/crediting=paired} (MEM). Memory ON is
the recommended exploratory default: split 1/1 on val MMR but campaign-best on TEST
by +7.3 pts, with crediting verified live; keep the no-memory arm as the control in
any A/B.
\item \textbf{Selection \& eval}: winner by pooled MMR (paired duels), never
single-eval rank; K=5 re-eval with vectors for any headline number; TEST-split hard
metric for external claims; seed anchor evaluated under the same protocol.
\item \textbf{Ops}: mirror the ALL-IN launcher: model smoke checks, treatment
self-check greps on the composed config, watchdog with 1h hard gate, run-end
automation (MMR + test eval), Telegram with local log echo.
\end{itemize}
