----------------------------------

the locked fit/score API and the locked evaluator.

Hard constraints from this chat + TZ:
  never change split r0, validate.py metrics, or test.py protocol
  never use val/test labels for preprocessing or hard-negative sampling
  no categorical features
  output of compiled program is a score; TZ asks [0,1] probability after
  calibration.temperature; evaluator only needs ranking (higher=binder)

  so inputs.pdb.kind = "complex" is the factual default after extract

  protein_lm pretrained weights: fixed runner set only, no network
